DefaultValuesProvider

open class DefaultValuesProvider : ValuesProvider

Default implementation of ValuesProvider, provides default values, reads localized strings out of resource files (strings.properties). This class can be subclassed in order to selectively customize the text and values in the various views that are presented (e.g. invitations, notifications, etc.).
